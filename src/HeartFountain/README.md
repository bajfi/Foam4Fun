# HeartFountain - Heart-Shaped Particle Fountain


## Overview

**HeartFountain** couples an incompressible carrier flow with a colliding particle cloud. Its main features are:

1. **Custom injector model** (`continuousManualInjection`) built as a user library
2. **Heart-shaped injector layout** generated by `case/script.py`
3. **Time-varying injection speed** using `Umag sine` coefficients
4. **Particle-cloud / flow coupling** through source terms in the momentum equation



## Building

### Prerequisites

- OpenFOAM (v2306+ recommended, case files here use v2312 headers)
- C++17-capable compiler
- Python 3 (for regenerating injector positions)
- Python packages: `numpy`, `matplotlib`

### Build Instructions

Build the custom injection library first, then the solver:

```bash
cd src/HeartFountain/app/ContinuousManualInjection
wmake libso

cd ../
wmake
```

This produces:

- `libContinuousManualInjection` in `$FOAM_USER_LIBBIN`
- `HeartFountain` executable in `$FOAM_USER_APPBIN`

## Running the Simulation

1. Go to the case directory:

   ```bash
   cd src/HeartFountain/case
   ```

2. (Optional) Regenerate heart-curve injector points:

   ```bash
   python3 script.py
   ```

3. Generate mesh:

   ```bash
   blockMesh
   ```

4. Run solver:

   ```bash
   HeartFountain
   ```

## Key Configuration

### Particle Injection (`constant/kinematicCloudProperties`)

Important fields under `injectionModels.model1`:

- `type`: `continuousManualInjection`
- `patch`: `movingWall`
- `positionsFile`: heart-curve points used as injectors
- `parcelsPerSecond`: injection rate
- `Umag`: time function for injection speed (`sine` in this case)
- `sizeDistribution`: fixed parcel diameter (`7e-4`)

### Carrier Flow and Domain

- `system/blockMeshDict`: single hexahedral block (`20 x 20 x 6` cells)
- `constant/transportProperties`: Newtonian fluid, `rho = 1000`, `nu = 0.01`
- `constant/g`: gravity `(0 0 -9.81)`
- `constant/turbulenceProperties`: laminar model

## Physical Model

The solver advances the carrier-phase momentum while exchanging momentum with the particle cloud:

$$
\frac{\partial (\alpha_c \mathbf{U})}{\partial t} + \nabla \cdot (\alpha_c \phi \mathbf{U}) = -\nabla p + \nabla \cdot \tau + \mathbf{S}_{cloud}
$$

where:

- $\alpha_c$: continuous-phase volume fraction
- $\mathbf{U}$: carrier velocity
- $\mathbf{S}_{cloud}$: particle-to-fluid momentum source

Particle injection directions are initialized from heart-curve tangents (see `case/script.py`).
